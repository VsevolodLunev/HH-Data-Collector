
## Описание проекта

Проект **HH-Data-Collector** предназначен для сбора данных о компаниях и вакансиях с сайта hh.ru через публичное API, проектирования таблиц в базе данных PostgreSQL и загрузки полученных данных в созданные таблицы.

## Требования

Для запуска проекта необходимы следующие инструменты:

- Python 3.8+
- PostgreSQL
- Poetry (для управления зависимостями)

## Установка и запуск

1. **Клонируйте репозиторий:**

```bash
git clone https://github.com/VsevolodLunev/HH-Data-Collector.git
cd HH-Data-Collector
```

2. **Создайте виртуальное окружение и установите зависимости:**

```bash
poetry init
poetry install
```

3. **Настройте базу данных PostgreSQL:**

   - Создайте базу данных и пользователя.
   - Отредактируйте файл `.env` с настройками подключения к базе данных.

4. **Запустите проект:**

```bash
poetry run python main.py
```
